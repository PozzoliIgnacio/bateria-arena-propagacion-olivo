# prototipo/

Registro físico del armado del prototipo (40x40x40 cm en su versión de laboratorio).

* Fotos y videos del proceso de construcción/ensamblado.
* `BOM.md` o `BOM.xlsx` — Lista de materiales (Bill of Materials) con cantidades, proveedores y costos, útil para justificar presupuesto ante el organismo de financiación.
* Notas de seguridad relevantes al manipular arena a alta temperatura (hasta 500 °C) y resistencias eléctricas.
