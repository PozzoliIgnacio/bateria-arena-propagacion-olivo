# simulaciones/Simulaciones computacionales del comportamiento térmico del acumulador (carga/descarga de calor, gradientes de temperatura).* `resultados/` — Capturas, gráficos de gradiente térmico, curvas de carga/descarga.* `scripts/` — Scripts de post-proceso (Python/MATLAB) para analizar y graficar resultados exportados.El objetivo de esta etapa es predecir el gradiente térmico y la inercia del sistema **antes** de fabricar el prototipo, y luego comparar contra los datos reales en `datos\\\\\\\_experimentales/`.
