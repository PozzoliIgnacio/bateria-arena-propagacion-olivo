# cad/

Modelos CAD del acumulador térmico (contenedor cilíndrico, chasis integrado, sistema de intercambio).

* `conceptual/` — Bocetos y modelos de la fase de ingeniería conceptual (exploración de geometría, forma cilíndrica vs. otras).
* `detalle/` — Modelos definitivos de ingeniería de detalle, con las revisiones (`v1`, `v2`, ...).
* `planos/` — Exportaciones 2D (PDF/DWG).
