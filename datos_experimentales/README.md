# datos\_experimentales/

Datos de ensayos reales con el prototipo físico, para validar los modelos de `calculos/` y `simulaciones/`.

* `raw/` — Datos crudos tal como los exporta el datalogger, sin modificar. 
* `procesados/` — Datos limpios/procesados, listos para graficar o comparar contra simulación.
