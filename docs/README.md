# docs/

Documentación formal del proyecto.

* `requerimientos/` — Requerimientos generales y específicos (ambiente de uso, rangos de temperatura, automatización/telemetría).
* `ingenieria\\\_basica/` — Entregables de la fase de ingeniería básica: relevamiento del estado del arte, modelo matemático seleccionado, análisis de condiciones ambientales del invernadero.
* `ingenieria\\\_detalle/` — Entregables de ingeniería de detalle: cálculo estructural del tanque, diseño del intercambiador de calor, resultados de simulación.
